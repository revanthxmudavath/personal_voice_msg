## Scope and architecture

- T07 remains deterministic and exposes no runtime agent.
- Every query goes through the trusted SearXNG search endpoint. The
  application does not call source APIs directly and has no arbitrary-URL
  fetch path.
- The three fixed searches use SearXNG's Startpage (`!sp`), Wikisource
  (`!ws`), and Wikiquote (`!wq`) engines.
- Search results are filtered to the code-owned source set before T06 creates
  opaque, run-scoped, single-use result IDs.
- The active source set is Standard Ebooks, English Wikisource, and English
  Wikiquote. Each source is exercised by the live gate.
- T06 revalidates public DNS, redirects, TLS, media type, framing, deadlines,
  and size before Trafilatura sees a page.
- The generator will not receive a raw passage. T08 must build its sanitized
  card inside the trusted transient callback, and T10 must perform source-copy
  comparison in the same lifecycle before the local text reference is
  discarded.

## Source and rights correction

The prerequisite review removed two earlier sources:

- `poets.org` terms prohibit the planned automated third-party copying and
  scraping use.
- ordinary `gutenberg.org` pages are designated for human access; Project
  Gutenberg directs automation to separate harvest/catalog channels that do
  not match T07's result-ID page-fetch flow.

Standard Ebooks is retained as the non-Wikimedia general-web source.
Wikisource and Wikiquote are retained as source-specific search engines for
historical creative text, lyrics, and quotations. Public availability and
platform licensing do not certify rights in an individual work or quotation.
Every rule therefore says that item-specific rights remain `unknown` until T08
validates evidence; unknown rights never become licensed by inference.

## Transient provenance lifecycle

The prior callback received only extracted text and T07 discarded it before
returning provenance. That made the planned T08/T10 lifecycle impossible
without either retaining raw text or fetching twice.

The surgical correction constructs an immutable `DiscoveryRecord` immediately
after the successful fetch and extraction, invokes the trusted analyzer with
`(text, record)`, and then deletes T07's local text reference before returning
that same record. Non-`None` analyzer output and ordinary analyzer exceptions
still fail closed with a generic extraction error. Raw bytes, extracted text,
and analyzer output remain absent from records, representations, and logs.
