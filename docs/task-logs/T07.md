## Scope and architecture

- T07 is a deterministic web-discovery workflow, not an agent runtime.
- It depends on the T06 result-ID boundary for all public page fetches.
- A trusted private SearXNG endpoint executes only three predefined,
  English-language romantic-theme queries.
- Search results are filtered to configured source domains before T06 creates
  sanitized metadata and opaque, run-scoped, single-use result IDs.
- Callers cannot provide an arbitrary URL.
- Trafilatura extracts supported HTML only after T06 has revalidated its public
  destination, redirects, media type, response framing, deadline, and size.
- Accepted plain text is decoded directly from T06's bounded bytes with strict
  UTF-8, normalized line endings, control checks, and the same content bounds.
- T09 may later expose these operations as restricted agent tools. It must not
  give an agent generic HTTP, filesystem, shell, delivery, or secret access.

## Assumptions, boundaries, and residual risks

- The SearXNG base URL is trusted deployment configuration, not model or page
  input. The application disables ambient proxies, cookies, redirects, and
  automatic decompression for the SearXNG API request.
- The source list is code-owned configuration. It includes Project Gutenberg,
  Standard Ebooks, and Academy of American Poets. Public accessibility is not
  treated as proof of copying rights; unknown rights remain explicit.
- Extracted page text is passed only to a trusted, `None`-returning in-process
  analyzer. Non-`None` returns and ordinary analyzer exceptions fail closed
  without formatting or retaining their values.
- A record contains only its opaque result ID, final source URL, authoritative
  UTC fetch-boundary time, and rights evidence. The constructor-injected clock
  is called immediately after a successful T06 fetch; runtime callers cannot
  supply a retrieval timestamp.
- T07 emits provenance only and intentionally creates no InspirationCard or
  retained analyzer payload. InspirationCard validation and copied-passage
  removal remain outside T07 and belong to T08.
- T07 constrains application-level discovery requests but does not claim
  deployment-level egress isolation. The private SearXNG deployment and
  production network isolation remain residual risks until T18.

## Implementation

- Added `trafilatura 2.1.0` and locked all transitive dependencies.
- Added bounded SearXNG JSON parsing with a 1 MiB response limit, a 10-second
  request deadline, fixed search parameters, curated-domain filtering,
  malformed-result skipping, canonical URL deduplication, and a 20-hit cap.
- Added source rules with bounded rights evidence and validated hostnames.
- Added transient HTML extraction with Trafilatura, comments and tables
  excluded, precision favored, a second media-type check, normalized parser
  failures, and a 40-to-100,000-character accepted range.
- Added explicit `text/plain` handling using strict UTF-8 with optional BOM,
  normalized CRLF and CR line endings, prohibited control-character rejection,
  and the same 40-to-100,000-character range.
- Normalized bounded deep-JSON recursion failures before result registration.
- Isolated JSON decoding in a helper that catches only `JSONDecodeError`,
  `UnicodeDecodeError`, and `RecursionError`, then returns a boolean/value
  tuple. The caller raises the fixed search error only after the raw-bearing
  exception scope has ended; valid JSON `null` remains distinguishable from a
  decoding failure.
- Removed arbitrary analyzer output from `DiscoveryRecord`. Analyzers must
  return `None`; non-`None` values and ordinary exceptions fail closed without
  inspection, formatting, storage, or exception chaining.
- Isolated analyzer invocation and plain-text decoding in narrow helpers that
  return only non-sensitive success/failure values. Fixed extraction errors are
  raised by the caller after raw-bearing exception handlers have exited, so
  normalized failures have no cause or context.
- Removed caller-controlled retrieval time from `analyze_result()` and added a
  constructor-injected clock captured immediately after successful T06 fetch,
  validated as timezone-aware, and normalized to UTC.
- Added provenance records containing the opaque result ID, final source URL,
  authoritative UTC retrieval time, and rights evidence. Raw page bytes,
  extracted text, and analyzer output are excluded.
- Added a pinned real SearXNG Docker harness with an isolated JSON search
  engine and public-page fixture. The runner receives hostile proxy variables
  to prove the application does not inherit them.
- Added a dedicated T07 integration job to CI and an offline quality-job step
  for the loopback HTTP deep-JSON decoder regression.

The SearXNG request parameters and JSON enablement follow the official
[Search API](https://docs.searxng.org/dev/search_api.html) and
[settings documentation](https://docs.searxng.org/admin/settings/settings).
The fixture engine follows the official
[JSON engine contract](https://docs.searxng.org/dev/engines/json_engine.html).
Extraction uses Trafilatura's documented
[Python API](https://trafilatura.readthedocs.io/en/latest/usage-python.html).
