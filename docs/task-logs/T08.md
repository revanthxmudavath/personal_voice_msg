# T08 - InspirationCard and rights transformation

## Status

Implemented and verified on `task/T08-inspiration-card`.

## Prerequisites and assumptions

- T07 commit `ca2beec` is on `origin/main`, and the T08 branch was created
  from that clean commit.
- T03 already created `sources` and `inspiration_cards`, so T08 requires no
  schema migration.
- T04 already provides the six-consecutive-word source-copy comparison.
- T07 supplies immutable source URL, UTC retrieval time, and rights evidence
  beside transient extracted text, then discards its local text reference.
- T08 validates and binds semantic signals; it does not add a model, agent,
  persistence workflow, approval state, or generated message.
- Current source evidence is not item-specific proof. Every T08 card therefore
  remains `unknown`; page or platform prose cannot promote its rights category.

Three bounded read-only prerequisite audits independently confirmed that no
T03, T04, or T07 production change and no database migration were required.

## Implemented boundary

Added `personal_voice_msg.discovery.inspiration` with:

- a frozen, slotted `InspirationCard`;
- fixed canonical `Theme`, `Emotion`, `Imagery`, and `Tone` enums;
- a single conservative `RightsCategory.UNKNOWN`;
- one `build_inspiration_card(draft, source_text, provenance)` entry point;
- one generic `InspirationCardValidationError` that never includes rejected
  input.

The untrusted draft must be an exact plain dictionary containing only:

```text
theme
emotion
imagery
tone
```

Source URL, rights evidence, rights category, and discovery timestamp are
bound server-side from the T07 `DiscoveryRecord`. The opaque run-scoped result
ID is validated while building the card but is not retained as durable card
provenance.

The canonical vocabularies are intentionally small:

- themes: appreciation, affection, companionship, encouragement;
- emotions: gratitude, joy, warmth, calm;
- imagery: morning light, quiet garden, warm home, open sky;
- tones: gentle, playful, tender, reassuring.

This removes arbitrary creative wording before T10 and prevents page text from
smuggling a passage, message, instruction, approval, score, state, task, source,
or rights claim into the card. The joined semantic signals are also checked
with T04's existing source-span comparison while the raw page text is still
transient.

Provenance is revalidated:

- the result ID is nonempty, bounded, and opaque-token shaped;
- the source is an already canonical public HTTP(S) URL no longer than 2,048
  characters;
- rights evidence is nonempty, single-line, control-free, and no longer than
  1,000 characters;
- the discovery timestamp is timezone-aware and normalized to UTC;
- source text must remain inside T07's established extraction bounds.

The card has no approval, state, score, task, generated-message, quote, lyrics,
or passage field. Direct construction revalidates the card's runtime types and
canonical timestamp and fails with the same generic error.

- canonical enums prevent source passages and injected fields from entering;

- cards are immutable and cannot self-approve;
